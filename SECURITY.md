# Security policy

## Supported versions

Only the latest plugin release and the helper version it pins receive
security fixes.

## Report a vulnerability

Use GitHub private vulnerability reporting: **Security** > **Report a vulnerability**,
or open the [private report form](https://github.com/t-zero-dev/camy/security/advisories/new).
Do not open public issues for vulnerabilities.

Include:

- The affected plugin and helper versions.
- Steps to reproduce the problem, with a proof of concept if possible.
- The impact and any relevant logs or configuration, with secrets removed.

CamY has a solo maintainer. Responses are best effort, with an aim to
acknowledge reports within about a week.

## Security fixes

Fixes ship in a helper release, then a plugin release that pins it.
Release notes credit the reporter unless they prefer otherwise.
